Hello from the cloud.

This page lives in a Git repository. Every push to main updates the servers behind it, and the fleet grows or shrinks with demand.

How it works

How it works

  1. Edit a file in site/ and push to GitHub.
  2. GitHub Actions uploads the files to a private storage bucket.
  3. Every VM pulls the latest files within a minute.
  4. Autoscaling adds VMs under load and removes them when traffic drops.
